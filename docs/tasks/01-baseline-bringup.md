# Task 01: native 4:3 baseline bring-up of Top Gear 2 (USA)

Read `AGENTS.md` (repo root) first, then `segagenesisrecomp/CLAUDE.md`,
`segagenesisrecomp/PRINCIPLES.md`, `segagenesisrecomp/DEBUG.md`, and the
reference game repo `~/git/tg2-deps/RocketKnightAdventuresRecomp`
(`DEVELOPMENT.md`, `CMakeLists.txt`, `game/game.toml`, `game/rka_spec.c`,
`tools/build-linux.sh`).

Work on a new branch `bringup/baseline` in this checkout. Commit in small
steps. Don't push.

## Goal

A native Linux build, `TG2Recomp`, generated by `GenesisRecomp` from the
stock ROM at `~/roms/genesis/tg2.bin`. It boots Top Gear 2 through the
logos and title, into the menus and **into an actual race**, with correct
graphics (road, cars, HUD) and audio running. 4:3 only. No widescreen or
60 fps work in this task.

## Steps (adapt as needed)

1. Create the game project in this repo modelled on RKA:
   - top-level `CMakeLists.txt` consuming the `segagenesisrecomp/` submodule
     and `recomp-ui/`;
   - `game/game.toml` (prefix `tg2`, heuristic discovery,
     `jump_table_autodiscovery = true`, `[ram_layout]` with the real SSP);
   - `game/tg2_spec.c` (entry `$000200`, V-int `$FF01EA` and H-int
     `$FFF9FE`, both RAM trampolines; `expected_rom_crc32 = 0xBD3074D2`;
     `tier3_floor_default = 1` during bring-up);
   - `tools/build-linux.sh` (Ninja, Release; the ROM path is an argument
     defaulting to `~/roms/genesis/tg2.bin`).
2. Find out how the RAM interrupt trampolines at `$FF01EA` / `$FFF9FE` get
   installed (the boot code copies them), and make sure V-int and H-int
   reach recompiled ROM code. This is the most likely early blocker.
3. Iterate the discovery loop until a race is reachable:
   - run headless with a TCP port, as DEBUG.md describes;
   - drive input over TCP (`set_input`) through title → menus → race;
   - read `dispatch_misses.toml` / `floor_coverage.toml`;
   - root-cause each miss against a raw-ROM disassembly (capstone or the
     engine's tools; write a small `tools/disasm_tg2.py` like RKA's);
   - fix it in `game.toml` or discovery evidence, then regenerate.
4. Capture evidence: PNG screenshots via the TCP screenshot command at the
   title, a menu and mid-race. Store them under `build/` (git-ignored) and
   list their paths in the report. Also record framebuffer hashes for
   frames 60 and 300 of a cold boot.
5. Write `docs/BRINGUP.md`: ROM facts, interrupt setup, the discovery
   loop history (functions found and misses per stage), and known issues.
   Start `docs/RAM_MAP.md` with every RAM address you identify (game mode,
   frame counter, camera/road state, player speed, input).

## Constraints

- Follow AGENTS.md. Never edit generated C. Never commit ROM-derived data.
  Executed-PC lists and discovery TOMLs of addresses are fine to commit;
  RKA does the same.
- If the engine has a genuine bug blocking this, fix it minimally in the
  submodule working tree, export it as a patch to
  `patches/segagenesisrecomp/`, and explain it in the report. Known
  upstream issue: `tests/runtime/game_video_frame_test.c` fails `-Werror`
  (missing `presentation_state_save` initializer). It's test-only and
  irrelevant here.
- No sudo. If something system-level is truly needed, stop and `ask`.

## Done means

- `tools/build-linux.sh` builds `TG2Recomp` from a clean `build/` (exit 0).
- A scripted TCP run reaches an in-race frame, with screenshots showing
  correct road, cars and HUD.
- The report states the `dispatch_misses.toml` count and the floor
  activity after a run that reaches a race.
- `docs/BRINGUP.md` and `docs/RAM_MAP.md` are committed.

If you can't get all the way into a race, the deliverable is how far you
got, with evidence and a precise root-cause hypothesis for the next
blocker. Report that as a partial result, not a success.
