# Top Gear 2 Recomp v0.1.0

Top Gear 2 Recomp is a native static recompilation of *Top Gear 2* (USA) for the Sega Genesis / Mega Drive. The game's 68000 code is translated to C and compiled into a native program — no emulator core is involved.

## Before you start

You must supply your own **Top Gear 2 (USA)** ROM. The game identifies it by content (**CRC32 `BD3074D2`**, 1,048,576 bytes), so any filename and extension work. No ROM is included.

## Downloads

| Platform | File |
| --- | --- |
| Linux / Steam Deck | `TG2Recomp-x86_64.AppImage` (single file) or `TG2Recomp-linux-x86_64.tar.gz` |
| Windows | `TG2Recomp-windows-x64.zip` |
| macOS (Apple Silicon and Intel) | `TG2Recomp-macos.zip` |
| Checksums | `SHA256SUMS` |

## Install (short)

- **Linux AppImage:** put the `.AppImage` and your ROM in the same folder, make it executable once (`chmod +x TG2Recomp-x86_64.AppImage` or file properties), then run it. If FUSE is unavailable, run `./TG2Recomp-x86_64.AppImage --appimage-extract-and-run`.
- **Linux tarball / Windows:** extract the archive, put your ROM next to `TG2Recomp` / `TG2Recomp.exe`, and run it.
- **macOS:** extract the zip, move `TG2Recomp.app` to *Applications*, remove quarantine once in Terminal (`xattr -dr com.apple.quarantine /Applications/TG2Recomp.app`), then open the app and pick your ROM in the launcher (the app copies it to `~/Library/Application Support/TG2Recomp/`).
- **Steam Deck:** in Desktop Mode add the AppImage as a non-Steam game; it runs with the built-in controls in Game Mode.

See the [README](https://github.com/vittau/top-gear-2-genesis-pc#download-and-install) for full per-platform instructions.

## Main features

- Original, Adaptive, 16:9, 21:9 and 32:9 display modes; road, scenery, opponents and roadside objects extend into the extra width, including rain and snow.
- True 60 fps races (interpolated presentation; gameplay, physics and lap times stay identical to the original). Adds 50 ms of display latency; can be turned off.
- Music and sound effects together via the new **BOTH** choice in the game's *Sound → Race Sound* menu.
- Hide overscan (on by default) to crop the empty top/bottom race bands.
- HUD centered or at the edges in widescreen.
- Linear filter (Graphics), off by default, with no edge artifacts at the picture boundary.
- Launcher and in-game options menu (controller-friendly), save states, rewind and fast-forward. Save/load notices appear at the top left; a save requested between races is written at the start of the next race (`SAVING AT NEXT BOUNDARY...`).
- Passwords work as on the cartridge. Use **CONTINUE → PASSWORD** (not **COUNTRY SELECT**) to restore money/parts; the password symbol is **V** (not U).

## Hotkeys / controls

| Action | Keyboard | Gamepad |
| --- | --- | --- |
| Genesis A / B / C (default: brake / accelerate / nitro) | Z / X / C | B / A / X |
| Options menu | Esc | Back + RB |
| Fullscreen | F11, Alt+Enter, or Ctrl/Cmd+F | |
| Save state (slots 1–9) | Shift+F1 … Shift+F9 | |
| Load state (slots 1–6, 9) | F1 … F6, F9 | |
| Save-state browser | F7 | |
| Rewind | F8 | Back + R3 |
| Fast-forward (hold) | Tab | |

On Mac keyboards, use **fn** with function keys unless standard function keys are enabled in *System Settings → Keyboard*.

## Known limitations / validation

- The owner has played the **macOS (Apple Silicon)** build. **Windows, Linux (including the Steam Deck and Linux tarball/AppImage) and macOS on Intel** are built in CI and pass headless smoke tests, but they have not been validated by play on real hardware yet; treat those builds as release candidates.
- Menus, the shop and results screens are shown in their original width, centred.
- With every option off, the picture is byte-identical to the original game.

# Top Gear 2 Recomp v0.1.0 (Português)

Top Gear 2 Recomp é uma recompilação estática nativa de *Top Gear 2* (USA) para Sega Genesis / Mega Drive. O código 68000 do jogo é traduzido para C e compilado em um programa nativo — sem núcleo de emulador.

## Antes de começar

Você precisa fornecer a sua própria ROM de **Top Gear 2 (USA)**. O jogo a identifica pelo conteúdo (**CRC32 `BD3074D2`**, 1.048.576 bytes), então qualquer nome e extensão funcionam. Nenhuma ROM é incluída.

## Downloads

| Plataforma | Arquivo |
| --- | --- |
| Linux / Steam Deck | `TG2Recomp-x86_64.AppImage` (arquivo único) ou `TG2Recomp-linux-x86_64.tar.gz` |
| Windows | `TG2Recomp-windows-x64.zip` |
| macOS (Apple Silicon e Intel) | `TG2Recomp-macos.zip` |
| Verificação | `SHA256SUMS` |

## Instalação (resumo)

- **AppImage do Linux:** coloque o `.AppImage` e a ROM na mesma pasta, torne-o executável uma vez (`chmod +x TG2Recomp-x86_64.AppImage` ou pelas propriedades do arquivo) e execute. Se o sistema não tiver FUSE, use `./TG2Recomp-x86_64.AppImage --appimage-extract-and-run`.
- **Tarball do Linux / Windows:** extraia o arquivo, coloque a ROM ao lado de `TG2Recomp` / `TG2Recomp.exe` e execute.
- **macOS:** extraia o zip, mova `TG2Recomp.app` para *Aplicativos*, remova a quarentena uma vez no Terminal (`xattr -dr com.apple.quarantine /Applications/TG2Recomp.app`) e abra o app para escolher a ROM no launcher (o app copia a ROM para `~/Library/Application Support/TG2Recomp/`).
- **Steam Deck:** no Modo Desktop, adicione o AppImage como jogo não Steam; ele roda com os controles integrados no Modo Jogo.

Veja o [README](https://github.com/vittau/top-gear-2-genesis-pc#download-and-install) para instruções completas por plataforma.

## Principais recursos

- Modos de exibição Original, Adaptativo, 16:9, 21:9 e 32:9; pista, cenário, adversários e objetos à beira da estrada se estendem na largura extra, inclusive chuva e neve.
- Corridas em 60 fps reais (apresentação interpolada; jogabilidade, física e tempos de volta ficam idênticos ao original). Adiciona 50 ms de latência de exibição; pode ser desligado.
- Música e efeitos sonoros juntos pela nova opção **BOTH** no menu *Sound → Race Sound* do jogo.
- *Hide overscan* ligado por padrão, cortando as faixas vazias em cima e embaixo nas corridas.
- HUD centralizado ou nas bordas em widescreen.
- Filtro linear (Gráficos), desligado por padrão, sem artefatos nas bordas da imagem.
- Launcher e menu de opções no jogo (compatível só com controle), save states, retrocesso e avanço rápido. Avisos de salvar/carregar aparecem no canto superior esquerdo; um salvamento pedido entre corridas é gravado no início da próxima corrida (`SAVING AT NEXT BOUNDARY...`).
- As senhas funcionam como no cartucho. Use **CONTINUE → PASSWORD** (não **COUNTRY SELECT**) para restaurar dinheiro e peças; o símbolo da senha é **V** (não U).

## Limitações conhecidas / validação

- O mantenedor jogou o build de **macOS (Apple Silicon)**. **Windows, Linux (incluindo Steam Deck e tarball/AppImage do Linux) e macOS em Intel** são gerados no CI e passam em testes *headless* de inicialização, mas ainda não foram validados jogando em hardware real; trate esses builds como candidatos a release.
- Menus, loja e telas de resultado são exibidos na largura original, centralizados.
- Com todas as opções desligadas, a imagem fica idêntica, byte a byte, à do jogo original.
