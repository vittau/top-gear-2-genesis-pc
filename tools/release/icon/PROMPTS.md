# Photorealistic icon exploration

Tool: built-in `image_gen.imagegen`, generation mode (no reference images sent to the model).
Settings: `transparent_background=false`; square 1024×1024 requested in prompt; model, seed and quality are tool-managed and not exposed. Outputs are generative and cannot be regenerated byte for byte. The selected PNG master will be the authoritative source; composition/downsampling is deterministic.

The owner provided a cover reference, inspected read-only for broad mood only. It is not an image input and is not copied to the repository. These concepts are pending selection and live outside git in `build/icon/photo/`.

## Approved master: C — Crest of Fire

The owner selected C as-is. The authoritative source is now `tools/release/tg2recomp.png` (1024×1024 RGB, SHA-256 `8b0094d4e8c5e2f7d7a32cf0e3f463faeab409f373a476921ce276dd1a938236`). Keep this generated source; rerunning the generative prompt is an exploration, not a deterministic rebuild. The rejected concepts and generated 1254px working files remain outside git.

`python3 tools/release/make_icon.py --all` deterministically derives the approved car-front detail PNGs (16/24/32), the multi-size Windows ICO, and the 1280×640 social preview. This artwork command uses Pillow and DejaVu Sans (`--font` can supply its path); it is never needed for a normal build or release packaging. The plain social-preview heading reads “TG2Recomp”; it does not use the original cover lettering.

Normal builds use the stdlib-only `icon/embed_icon.py` to extract the ICO's 32px RGBA data into a build-local header. No generated C/header or additional runtime image decoder is stored in git or required in the release. macOS packaging uses the checked-in detail PNGs at 16/32 physical pixels and the approved master for larger sizes, through the existing `sips`/`iconutil` path.

Approved derivatives were rendered with Pillow 13.0.0. The resolved DejaVu Sans font was `/usr/share/fonts/TTF/DejaVuSans.ttf`, SHA-256 `6038a160b491e121c1f12c7bccb4a9c8730296e3adc1086a059404ed84b7451c` (Pillow resolves the default font argument by filename on this host). Use `--font` to point at that font on another machine.

## macOS bundle derivative

macOS packaging now runs `macos_icon.swift` on the same approved master. It
uses Apple's public SwiftUI `RoundedRectangle` with continuous corners
(radius 185) on an 824×824 body centred at (100,100) in a transparent
1024×1024 canvas, plus a CoreGraphics shadow (8px downward offset, 16px blur,
24% black). `sips` derives every ICNS size from this build-local PNG. No
second binary master or pip dependency is introduced; Windows ICO, embedded
32px window icon, Linux PNG, and social preview stay unchanged. The macOS
runtime preserves the bundle icon rather than replacing it with the small
embedded cross-platform icon.
